# RFSD — Разведочный анализ данных (EDA)


## Описание проекта

Данный репозиторий содержит результат разведочного анализа данных (EDA) финансовой отчётности
российских компаний из открытого датасета [RFSD (Russian Financial Statements Database)](https://github.com/irlcode/RFSD).

RFSD — первая открытая база данных с гармонизированными годовыми неконсолидированными
финансовыми отчётами всех активных компаний России за 2011–2024 гг. (~60 млн строк, ~165 колонок).

## Структура анализа

| Раздел | Содержание |
|--------|------------|
| 0. Импорт | Polars, Pandas, Matplotlib, Seaborn, SciPy |
| 1. Загрузка данных | Скачивание из Hugging Face, фильтрация filed==1, **случайная выборка 10 000 компаний по всей РФ** (sample, не slice) |
| 2. Описательная статистика | describe() + процент пропусков, заполнение пропусков в балансе нулями |
| 3. Гистограммы (log10) | Выручка, Чистая прибыль, Итого активы — все в **логарифмической шкале** + boxplot + IQR-выбросы |
| 4. Обнаружение аномалий | Отрицательные активы, отрицательный капитал, нулевая выручка при крупных активах |
| 5. Корреляция (Spearman) | **Ранговая корреляция Спирмена** (не Пирсон!), heatmap 13 показателей |
| 6. Scatter plots | Выручка vs Себестоимость, Выручка vs Активы, Возраст vs Рентабельность |
| 7. Секторы ОКВЭД | Медианная выручка, доля убыточных, boxplot рентабельности по отраслям |
| 8. Упрощённая форма | Сравнение полной (simplified=0) и упрощённой (simplified=1) форм отчётности |
| 9. Выводы | 6 ключевых выводов + ограничения исследования |

## Ключевые технические решения

1. **Случайная выборка (sample), не slice** — Parquet-файлы отсортированы по регионам, slice(0,N) вернул бы только Адыгею
2. **Логарифмическая шкала (log10)** — финансовые данные логнормальны, в линейной шкале гистограммы неинформативны
3. **Spearman, не Pearson** — ранговая корреляция устойчива к выбросам и ненормальности распределения
4. **|Себестоимость|** — в RFSD расходы хранятся отрицательными по правилам РСБУ
5. **Пропуски в балансе = 0** — для упрощённой формы отчётности отсутствие значения означает нулевой остаток

## Инструменты

- **Polars** — загрузка и обработка данных
- **Pandas** — манипуляции, описательная статистика
- **Matplotlib / Seaborn** — визуализация
- **NumPy / SciPy** — вычисления

## Как запустить

```bash
pip install polars pandas numpy matplotlib seaborn scipy huggingface_hub nbformat
jupyter notebook rfsd_analysis.ipynb
```

Данные загружаются из Hugging Face при выполнении ноутбука.
